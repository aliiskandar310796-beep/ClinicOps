# ClinicOps.dk Deployment Plan

## Objective

Deploy the ClinicOps intelligence layer publicly while keeping confidential client data private.

Principle:

`Public trust layer + private intelligence delivery`

## Public layer

Hosted through GitHub Pages where appropriate:

- Identifier Check
- Sanitized transition examples
- Research notes after evidence review
- Methodology
- Tools
- Educational content

## Private layer

Never publish:

- client portfolios
- confidential documents
- prospect data
- unpublished regulatory assessments

Private delivery:

`client intake → analysis → human review → secure report delivery`
