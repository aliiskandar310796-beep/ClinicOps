# ClinicOps claim rules

These are standing editorial and analytical constraints derived from the 8 September 2026 correction pass.

1. Never revive the claim that MDR class III manufacturer registrations generally lack linked SS(C)Ps.
2. Frame the commercial opportunity as transition backlog and document-operation complexity, not manufacturer negligence.
3. A B-prefix/legacy screening rule is a ClinicOps derivation/observed system behavior unless a primary source explicitly states the exact consequence being claimed.
4. Do not treat a procedure pack's class as proof that the pack itself underwent an ordinary class III device classification pathway.
5. Never imply complete public-register auditability through the known API routes.
6. Use issue dates for currency comparison when revision-number semantics are not proven equivalent.
7. "MATCH" means metadata identifiers/dates align; it never means document bodies were compared unless the actual files were retrieved and compared.
8. Public outputs must state sample design, retrieval limits, unresolved cases, and whether examples are anonymised.
