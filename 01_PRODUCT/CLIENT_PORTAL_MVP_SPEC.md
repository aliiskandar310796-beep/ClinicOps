# ClinicOps Client Portal MVP Specification

## Purpose

Convert ClinicOps internal intelligence capabilities into a client-facing delivery workflow.

The MVP is not a full SaaS product. It is an intelligence delivery portal that improves trust, repeatability and scalability.

## Client Journey

Lead
→ Assessment request
→ Secure intake
→ Portfolio/document submission
→ ClinicOps analysis
→ Human validation
→ Client report delivery
→ Feedback captured
→ Continuous improvement

## User Roles

### Client Administrator
- manages organisation access
- uploads information
- views reports

### Regulatory User
- reviews findings
- assigns actions
- downloads evidence packages

### ClinicOps Analyst
- validates findings
- controls publication
- manages intelligence outputs

## Core MVP Features

### 1. Intake

Capture:
- company
- contact
- device portfolio size
- device classes
- regulatory objectives
- uploaded documents

### 2. Portfolio View

Show:
- devices analysed
- transition status
- priority areas
- evidence confidence

### 3. Intelligence Report

Deliver:
- executive summary
- findings
- evidence references
- recommended actions
- limitations

### 4. Feedback Loop

Capture:
- client corrections
- questions
- missing information
- new opportunities

Feed learning back into Revenue OS and Knowledge Graph.

## Technical Principles

- Build service-first before SaaS complexity
- Preserve evidence provenance
- Keep human regulatory judgement in the loop
- Avoid unsupported automated conclusions
- Make every client engagement improve the system

## Long-Term Evolution

MVP portal
→ partner portal
→ regulatory intelligence platform

The goal is a Bloomberg-style intelligence layer for EU medical device operations.
