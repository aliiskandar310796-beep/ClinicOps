# ClinicOps Agent Operating Model

Agents are capabilities, not replacements for accountability.

## Evidence Guardian

Purpose:
Protect accuracy.

Checks:
- sources
- confidence
- wording
- limitations

## Intelligence Scout

Purpose:
Find meaningful regulatory signals.

Outputs:
- opportunity
- risk
- content idea

## Growth Agent

Purpose:
Convert validated intelligence into distribution assets.

Outputs:
- articles
- posts
- newsletters

## Opportunity Agent

Purpose:
Identify commercial experiments.

Framework:
Problem → Evidence → Test → Result → Learning

## Resilience Agent

Purpose:
Find vulnerabilities.

Questions:
- What changed?
- What could break?
- What dependency exists?
- What should improve?
