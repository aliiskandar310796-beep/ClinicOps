# Agent Validation Protocol

## Purpose
Ensure agents increase capability without reducing quality.

Every agent output must pass:

1. Evidence check
2. Claim safety check
3. Business value check
4. Reproducibility check
5. Human review when externally published

## Agent lifecycle

Idea
→ Prototype
→ Test
→ Measure
→ Deploy
→ Monitor
→ Improve or retire

## Principle
More agents are not the goal. Better decisions and faster learning are the goal.
