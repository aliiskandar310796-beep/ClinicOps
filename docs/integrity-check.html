Important boundary. This tool compares text you enter. It does not decide which source is legally authoritative, whether a field is required, or whether a difference is compliant. How to use the signal

  • MATCH means the entered value agrees with the chosen reference under the selected comparison mode.
  • DIFFERENT is a review signal: confirm whether the record should have changed, whether the reference is correct and who owns the decision.
  • NOT ENTERED means no value was supplied. It is not evidence that the real record is missing.
Good use: triage a change event, prepare a human review, or demonstrate a cross-surface reconciliation workflow. Not proof: this result is not a regulatory compliance determination and should not be used as one.
