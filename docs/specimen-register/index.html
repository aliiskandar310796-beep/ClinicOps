What makes the register evidence-first

Source ≠ observationThe approved reference and the downstream observed value remain separate records.
Signal ≠ conclusionDIFFERENT means text or declared data differs. It does not mean noncompliance.
Automation ≠ authorityWhen sources conflict, the workflow stops at unresolved authority and routes the decision to a named human owner.

Example evidence chain

1 · Reference evidenceApproved change record / controlled source
2 · ObservationDeclared downstream record and captured value
3 · Deterministic signalMatch / different / unresolved / not observed
4 · Human decisionAccept, correct, investigate, defer or close with rationale

ClinicOps can automate the structure and comparison. The accountable client role retains source-authority and release decisions.
