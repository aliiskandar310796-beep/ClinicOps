When a regulated fact changes, know what else must change.

ClinicOps helps medical-device manufacturers, authorised representatives and regulatory partners keep regulatory data, controlled documents and lifecycle changes aligned across the surfaces they put in scope.

We reconcile client-approved controlled sources against downstream records such as EUDAMED data, RIM/master data, IFU, SS(C)P, labels and artwork; preserve evidence; and route unresolved authority to the right human decision owner instead of guessing.

The operating problem

A regulatory change rarely lives in one place. The expensive failure mode is drift between sources, systems and documents: one value changes, another remains stale, two controlled sources disagree, or a team has to reconstruct later why a value was accepted.

Source authority

If supplied controlled sources conflict, ClinicOps records authoritative source unresolved. Client RA/QA decides what controls.

Cross-surface consistency

Declared values are reconciled only across the client-approved evidence population and fields in scope.

Change propagation

Approved old/new values are checked against the downstream surfaces the client identifies as affected.

One commercial flow: Review → Remediate → Maintain

What one live review looks like

Start small: one device family or Basic UDI-DI group, 1–3 client-approved controlled sources, 2–6 downstream surfaces, 3–10 declared fields, and one named qualified reviewer. The output is a bounded evidence/discrepancy pack, not an open-ended consultancy project.

MDR is the beachhead. The method is broader.

ClinicOps is developing the same evidence-control method for clinical work where one approved change must propagate across records, systems, vendors and human review. Adjacent launch experiments cover protocol and study-change operations, QMS/change operations and evidence control around clinical AI.
