Regulatory Integrity Scanner

Check whether regulated facts remain consistent. Run a single-change check — one approved source against the downstream records that should reflect it — or a portfolio scan over a CSV, XLSX or JSON export. Deterministic comparison, bounded statuses, an exception queue with owners, and portable exports. Everything runs in this browser page; nothing you enter or import leaves it.

  • Runs locally — no upload
  • Deterministic rules
  • Bounded status vocabulary
  • CSV · XLSX · JSON import
  • CSV + JSON export
  • Human authority preserved
Boundary. The scanner compares the values you provide and structures review work. It does not decide which source is legally authoritative, does not make compliance determinations, and reports mismatch signals and missing evidence — never a compliance verdict in either direction. Interpretation and disposition stay with your qualified owner.

Export

Exports include every finding, the comparison input, rule version and full SHA-256 fingerprints. Review edits are local and self-reported; a fingerprint detects changes against a trusted copy but does not certify evidence or reviewer identity. Export before leaving this page.
