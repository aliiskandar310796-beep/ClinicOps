eCOA licence and translation lead-time planner

An eCOA study cannot start until every instrument exists, licensed, in every language, with screens that someone has checked. Enter the instruments and languages, the kick-off date and the date you need the first participant in. 3. Result

How the date is worked out

Licence and translation run side by side for each instrument and language. Screenshot review follows the translation. Copyright-holder sign-off follows the licence and the screenshot review. The study build runs from kick-off, and testing starts when the build and every language version are ready. A submission estimate, if you enter one, runs alongside and can set the date by itself. The three scenarios use the optimistic, likely and pessimistic figures throughout; the expected case weights the likely figure. The result is only as good as the durations entered.
