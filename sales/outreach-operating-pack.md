# ClinicOps Controlled Outreach Operating Pack

Status: internal commercial operating asset. Never commit private prospect lists, mailbox content, personal data or live buyer evidence here.

## Purpose

Convert the global 33-cell acquisition model into high-signal outreach without duplicate contact, fear-based messaging or unbounded blasting.

## Pre-send suppression gate

Before any outbound draft is eligible for sending, verify all applicable sources:

1. private outreach master;
2. HubSpot company/contact state;
3. Outlook Sent Items;
4. Gmail Sent Items;
5. permanent do-not-contact list;
6. jurisdiction / route suitability;
7. company-wide daily send count.

If any source is unavailable, the account is not automatically eligible. Record the missing check and route for human judgement.

Permanent suppression remains:

- Ergomed Group;
- PrimeVigilance.

Danish-domiciled organisations are not cold-emailed.

Company-wide cold-outbound ceiling remains 15 emails/day.

## Daily portfolio

Do not spend all 15 sends on one hypothesis. Default daily allocation:

- 5 high-fit manufacturers;
- 5 distribution / partner accounts;
- 5 ecosystem routes (communities, associations, events, directories or specialist service firms).

Reallocate only when evidence shows one lane is clearly outperforming.

## Message architecture

Every message should contain:

1. **Why this recipient** — one grounded reason.
2. **One workflow problem** — not a menu of services.
3. **One proof object** — specimen, tool, calculator or bounded research note.
4. **One question** — easy to answer without taking a meeting.
5. **Respectful exit** — no reply needed / happy to close the loop.

## Follow-up rule

A follow-up is permitted only when:

- the original message was delivered to a verified route;
- the account is not suppressed;
- the jurisdiction / route remains suitable;
- there is a meaningful new reason to contact, or one single polite follow-up is explicitly allowed by the current campaign policy.

Never create an automated sequence merely because there was no reply.

## Reply handling

Classify replies by evidence, not sentiment:

- routing / out-of-office / bounce = delivery evidence, not E4;
- substantive human response = E4;
- repeated workflow pain + consequence = E5;
- request for scope, pricing, procurement path or identifiable budget owner = E6;
- activated paid work / PO path = E7;
- accepted delivery / payment = E8;
- repeat / expansion / referral = E9.

Compliments without workflow evidence remain E4 at most.

## Buyer-conversation conversion

When a buyer engages, stop pitching and diagnose:

- what changed;
- which source should control;
- which downstream surfaces are affected;
- how the team checks them today;
- what gets delayed or reworked;
- who owns the decision;
- how often the workflow occurs;
- what a bounded successful review would need to produce;
- whether the buyer can sponsor a real scope.

The next step should be the smallest real commercial commitment that tests value.

## Instrumentation

For every delivered test, record privately:

- account / cell;
- route and jurisdiction basis;
- suppression checks completed;
- message hypothesis;
- proof object used;
- send date;
- delivery result;
- human response result;
- evidence stage;
- objection / pain / consequence;
- next action;
- whether the channel should be reinforced, changed or killed.

Never place that private log in the public repository.
