# Continuous Improvement Loop

## Weekly cycle

1. Collect signals
2. Validate evidence
3. Create hypothesis
4. Run smallest useful experiment
5. Measure outcome
6. Capture learning
7. Improve system

## Quality gates

Before publishing:

- source verified
- limitations stated
- claim strength matches evidence

Before building:

- customer value identified
- measurable outcome defined
- maintenance cost considered

## Goal

Create a company that becomes more capable after every cycle.
